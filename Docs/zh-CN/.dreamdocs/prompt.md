Fixed labels. When a slot starts with one of these bold labels, write the label exactly as given here, punctuation included, inside the bold:

- `**Severity**` -> `**严重性**`; its value: error -> 错误, warning -> 警告, info -> 信息
- `**Message**` -> `**消息**`
- `**Raised by**` -> `**触发位置**`
- `**Cause.**` -> `**原因。**`
- `**Fix.**` -> `**修复。**`
- `**Note:**` -> `**注意：**`, `**Note.**` -> `**注意。**`
- `**Warning:**` -> `**警告：**`
- `**Explanation:**` -> `**说明：**`
- `**See**` -> `**参见**`
- `**Unverified:**` -> `**未验证：**`
